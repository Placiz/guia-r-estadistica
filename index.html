R para estadística descriptiva

Aprende a resumir, ordenar y graficar datos con R, aunque nunca hayas programado. Cada lección explica la idea con palabras simples, trae código que puedes copiar y ejecutar, un ejercicio para practicar y una pregunta rápida para comprobar que lo entendiste.

Antes de empezar

Objetivo: tener R funcionando y saber dónde escribir tu primer código.

R es un lenguaje de programación pensado para trabajar con datos. En lugar de hacer clics como en Excel, le escribes instrucciones. Al principio parece más lento, pero tiene una ventaja enorme: tu análisis queda guardado como una receta que puedes repetir, corregir o compartir.

AnalogíaR es el motor de un auto y RStudio es el tablero. Puedes usar R solo, pero RStudio te da volante, espejos y velocímetro. Instala los dos.

Paso 1. Instalar (una sola vez)

  1. Descarga e instala R desde cran.r-project.org (elige tu sistema: Windows, Mac o Linux).
  2. Después instala RStudio Desktop desde posit.co/download/rstudio-desktop.
  3. Abre RStudio, no R. RStudio encuentra R solo.
¿No puedes instalar nada?Usa Posit Cloud: es RStudio dentro del navegador, con una cuenta gratuita.

Paso 2. Conocer RStudio

RStudio tiene cuatro paneles:

ScriptDonde escribes y guardas tu código (archivo .R). Ábrelo con Archivo → Nuevo archivo → R Script.
EntornoLista de los objetos que has creado (tus datos, variables).
ConsolaDonde R ejecuta las órdenes y muestra los resultados.
Archivos / Gráficos / AyudaAquí aparecen tus gráficos y la documentación.

Escribe en el script, coloca el cursor en una línea y pulsa Ctrl + Enter (en Mac Cmd + Enter). La línea se ejecuta y el resultado aparece en la consola.

Paso 3. Tu primer código

print("Hola, estadística")
[1] "Hola, estadística"

El [1] no es parte de la respuesta: R te dice que ese es el elemento número 1 del resultado. Lo verás siempre.

Paso 4. Pedir ayuda

Cualquier función tiene su manual. Escribe un signo de pregunta delante del nombre:

?mean        # abre la ayuda de la función mean (media)
help(median) # otra forma de hacer lo mismo

Todo lo que va después de # es un comentario: R lo ignora. Úsalos para explicarte a ti mismo qué hace cada línea.

Comprueba

Escribiste código en el script. ¿Cómo lo ejecutas?

Operaciones

sqrt() y round() son funciones: un nombre seguido de paréntesis. Dentro van los argumentos, separados por comas. round(3.14159, 2) significa “redondea 3.14159 a 2 decimales”.

Ojo con el decimalEn R el decimal siempre se escribe con punto: 3.5. La coma separa argumentos. round(3,5) no es “tres coma cinco”.

Objetos: guardar valores con nombre

Para guardar un resultado usas la flecha <- (se escribe con < y -, o con el atajo Alt + -).

edad_meses <- edad * 12

AnalogíaUn objeto es una caja con etiqueta. edad <- 20 es “mete el 20 en una caja llamada edad”. Después solo dices “edad” y R saca lo que hay dentro. Mira el panel Entorno: la caja aparece ahí.

Reglas de nombres: empiezan con letra, sin espacios ni tildes (usa _ o .), y R distingue mayúsculas: Edad y edad son dos objetos distintos.

Filtrar con condiciones

Una comparación devuelve TRUE (verdadero) o FALSE (falso) para cada dato. Si la pones dentro de los corchetes, R se queda solo con los verdaderos.

notas >= 8              # ¿cada nota es mayor o igual a 8?
notas[notas >= 8]       # solo las notas de 8 o más
sum(notas >= 6)         # cuántos aprobaron (TRUE cuenta como 1)
mean(notas >= 6)        # proporción de aprobados

[1] 8.2 9.0 8.5 9.4
[1] 10
[1] 0.8333333
El truco de TRUE = 1Sumar TRUE/FALSE cuenta cuántos cumplen la condición. Promediarlos da la proporción. Este truco lo usarás muchísimo.

Comparadores: == igual, != distinto, >, <, >=, <=. Para combinar: & (y), | (o).

NA: el dato que falta

En datos reales siempre falta algo: alguien no respondió una pregunta. R lo marca como NA (Not Available). Cualquier cuenta con un NA da NA, porque R no puede adivinar el valor.

edades <- c(20, NA, 22, 19)
mean(edades)                 # da NA
mean(edades, na.rm = TRUE)   # na.rm = "remove NA": ignora los faltantes
is.na(edades)                # ¿cuáles faltan?
sum(is.na(edades))           # cuántos faltan
[1] NA
[1] 20.33333
[1] FALSE  TRUE FALSE FALSE
[1] 1
Error frecuenteSi mean() te devuelve NA, casi siempre es porque hay datos faltantes. Agrega na.rm = TRUE. Funciona igual en median, sd, var, sum, min, max y quantile.

¿Media o mediana? El efecto de los valores extremos

Imagina cinco sueldos donde uno es del gerente:

sueldos <- c(1200, 1300, 1250, 1400, 15000)
mean(sueldos)
median(sueldos)
mean(sueldos, trim = 0.2)   # media recortada: quita el 20% de cada extremo
[1] 4030
[1] 1300
[1] 1316.667

La media dice que el sueldo típico es 4030, pero nadie excepto el gerente gana cerca de eso. La mediana (1300) describe mejor al grupo. Regla práctica: si hay valores extremos o los datos están muy cargados hacia un lado, reporta la mediana.

Media ponderada

Cuando cada dato pesa distinto, por ejemplo tres exámenes que valen 30%, 30% y 40%:

weighted.mean(c(8, 6, 9), w = c(0.3, 0.3, 0.4))
[1] 7.8
Tu turno: programa la moda R no trae una función para la moda estadística. Escribe una función moda(x) que devuelva el valor más repetido. Debería devolver 7.5 para notas. Piensa también qué pasa si dos valores empatan.
Ver una pista

table(x) cuenta cuántas veces aparece cada valor. max() te da la frecuencia más alta. names() te da los valores que corresponden a esas frecuencias.

Ver solución 
moda <- function(x) {
  frec <- table(x)                         # frecuencia de cada valor
  modas <- names(frec)[frec == max(frec)]  # los que tienen la frecuencia máxima
  as.numeric(modas)                        # names() da texto: lo pasamos a número
}
moda(notas)
moda(c(1, 1, 2, 2, 3))   # bimodal: devuelve las dos
[1] 7.5
[1] 1 2

Para variables de texto (por ejemplo, la carrera) quita la última línea as.numeric; si no, obtendrías NA. En la lección 15 aprenderás más sobre cómo crear funciones.

IntermedioLección 7

Medidas de dispersión

Objetivo: medir qué tan parecidos o diferentes son los datos entre sí.

Dos cursos pueden tener la misma media (7) y ser muy distintos: en uno todos sacaron cerca de 7, en otro la mitad sacó 4 y la otra mitad 10. La dispersión mide esa diferencia.

range(notas)           # mínimo y máximo
diff(range(notas))     # rango = máximo - mínimo
var(notas)             # varianza
sd(notas)              # desviación estándar
IQR(notas)             # rango intercuartílico (Q3 - Q1)
[1] 4.8 9.4
[1] 4.6
[1] 1.937197
[1] 1.391832
[1] 1.575
Cómo leer la desviación estándarEs la distancia típica de cada dato a la media, en las mismas unidades que tus datos. Aquí: las notas se alejan, en promedio, unos 1.4 puntos de la media 7.36.

Muestral vs. poblacional

var() y sd() dividen entre n - 1 (fórmula muestral), que es lo correcto cuando tus datos son una muestra. Si tienes toda la población y necesitas dividir entre n, calcúlalo a mano:

n <- length(notas)
sqrt(sum((notas - mean(notas))^2) / n)   # desviación estándar poblacional
[1] 1.332578

Coeficiente de variación (CV)

Sirve para comparar la dispersión de variables con unidades distintas (horas contra notas). Es la desviación estándar como porcentaje de la media.

cv <- function(x) sd(x) / mean(x) * 100
cv(estudiantes$nota)
cv(estudiantes$horas)
[1] 18.91505
[1] 39.14949

Las horas de estudio varían mucho más (39%) que las notas (19%). Una guía común: menos de 15% es poco disperso, más de 30% es muy disperso.

Medidas de posición y de forma

Objetivo: ubicar un dato dentro del grupo (cuartiles, percentiles, puntaje z), describir la forma de la distribución y detectar valores atípicos.

Cuartiles y percentiles

Los cuartiles parten los datos ordenados en cuatro partes iguales. El percentil 90 es el valor que deja por debajo al 90% de los datos.

quantile(notas)                  # cuartiles
quantile(notas, 0.90)            # percentil 90
quantile(notas, c(0.10, 0.90))   # percentiles 10 y 90
summary(notas)                   # resumen de 6 números

   Min. 1st Qu.  Median    Mean 3rd Qu.    Max.
  4.800   6.700   7.500   7.358   8.275   9.400
¿Por qué mi libro da otro cuartil?Hay varios métodos para calcular cuantiles. R usa por defecto el tipo 7. Si tu curso usa otro, cámbialo con quantile(notas, type = 6). Las diferencias son pequeñas.

Puntaje z (estandarizar)

Dice a cuántas desviaciones estándar de la media está cada dato. Positivo: por encima de la media. Negativo: por debajo.

z <- (notas - mean(notas)) / sd(notas)
round(z, 2)
# atajo: as.numeric(scale(notas)) da lo mismo
 [1]  0.10  0.60 -0.90  1.18 -1.41  0.32  0.82 -0.33 -0.11  1.47 -1.84  0.10

La nota 4.8 (z = −1.84) está casi dos desviaciones por debajo de la media: es la más rezagada del grupo.

Forma: asimetría y curtosis

  • Asimetría cercana a 0: simétrica. Negativa: cola larga hacia los valores bajos. Positiva: cola hacia los altos.
  • Curtosis (en exceso) cercana a 0: como la normal. Negativa: más aplanada. Positiva: más puntiaguda y con colas pesadas.
asimetria <- function(x) {
  m <- mean(x); n <- length(x)
  (sum((x - m)^3) / n) / (sum((x - m)^2) / n)^1.5
}
curtosis <- function(x) {
  m <- mean(x); n <- length(x)
  (sum((x - m)^4) / n) / (sum((x - m)^2) / n)^2 - 3
}
asimetria(notas)
curtosis(notas)

Correlación entre variables

  
Objetivo: medir si dos variables numéricas se mueven juntas y con qué intensidad.


  
El coeficiente de correlación va de −1 a 1. Positivo: cuando una sube, la otra también. Negativo: cuando una sube, la otra baja. Cerca de 0: no hay relación lineal.

  
cor(estudiantes$horas, estudiantes$nota)                       # Pearson
cor(estudiantes$horas, estudiantes$nota, method = "spearman")  # por rangos
round(cor(estudiantes[, c("edad", "horas", "nota")]), 2)       # matriz
[1] 0.9315614
[1] 0.9
      edad horas  nota
edad   1.00 -0.01 -0.15
horas -0.01  1.00  0.93
nota  -0.15  0.93  1.00


  

    
Valor absoluto de rInterpretación orientativa

    
      
0.00 – 0.29Débil o nula

      
0.30 – 0.69Moderada

      
0.70 – 1.00Fuerte

    
  

  
Horas y nota tienen una correlación fuerte y positiva (0.93). La edad casi no se relaciona con nada.

  
    
    
  • Pearson (por defecto): mide relación en línea recta. Sensible a atípicos.
    • 
    
  • Spearman: usa el orden de los datos. Mejor con atípicos, variables ordinales o relaciones curvas que siempre suben.
    • 
  

  
Correlación no es causalidadQue dos variables se muevan juntas no prueba que una cause la otra. Las ventas de helado y los ahogamientos están correlacionadas porque las dos suben en verano. Grafica siempre antes de concluir: plot(x, y).


  
Covarianza

  
cov(estudiantes$horas, estudiantes$nota)
[1] 4.65303

  
La covarianza indica la dirección, pero su tamaño depende de las unidades. Por eso para interpretar se usa la correlación, que es la covarianza estandarizada.

resumen <- function(x) {
  x <- x[!is.na(x)]        # quita faltantes
  c(n       = length(x),
    media   = mean(x),
    mediana = median(x),
    de      = sd(x),
    min     = min(x),
    max     = max(x),
