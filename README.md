# R para estadística descriptiva

Guía de estudio interactiva para aprender R aplicado a la estadística descriptiva, desde cero hasta un nivel avanzado.

**👉 Ver la guía:** https://placiz.github.io/guia-r-estadistica/

## Contenido

- **Básico:** instalación de R y RStudio, objetos, vectores, tipos de datos y NA, data frames, importar datos y paquetes.
- **Intermedio:** tendencia central, dispersión, posición y forma, valores atípicos, tablas de frecuencia, gráficos con R base y análisis por grupos.
- **Avanzado:** dplyr, ggplot2, correlación, funciones propias, informes con Quarto y un proyecto final.

Cada lección incluye código para copiar con su resultado esperado, ejercicios con pistas y soluciones, y preguntas de autoevaluación. También hay un laboratorio donde puedes calcular estadísticas con tus propios datos.
